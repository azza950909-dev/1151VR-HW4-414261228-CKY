製作流程和相關操作:首先開啟一個3D專案，再從Asset store找尋要用的無人機模型，再將模型匯入專案中，接著用unity新增障礙物、儲存點、終點等3D物件，並為障礙物掛上定點移動的腳本，然後再幫無人機建立腳本使之能夠進行移動旋轉等操作，
並搭載上audio source讓他播放引擎聲、撞擊聲等音效，再為攝影機寫跟隨腳本以跟隨無人機，接著再設定空氣牆以免玩家超出遊玩範圍，最後再設計教學UI以及獲勝UI，並讓Game Manager進行回到紀錄點、獲勝及控制UI等操作
